# Slide 02 — Self-Attention

## Status

implemented

---

# 1. Core takeaway

Self-attention allows each token representation to aggregate information
from other tokens using content-dependent interaction weights.

---

# 2. Audience outcome

After this slide, the audience should understand:

- Why Q, K, and V are separate learned projections.
- That attention weights are query-dependent.
- That each query aggregates values from the available keys.

---

# 3. Prerequisites

Assume knowledge of:

- matrix multiplication
- softmax
- learned linear projections

Do not explain:

- basic vector representations
- neural network layers

---

# 4. Technical content

Required operations:

Q = XW_Q
K = XW_K
V = XW_V

Attention(Q,K,V) =
softmax(QK^T / sqrt(d_k))V

The slide should visually distinguish:

1. projection into Q/K/V
2. similarity computation
3. normalization
4. weighted aggregation

---

# 5. Critical correctness constraints

The slide MUST NOT imply that:

- Q, K, and V originate from different input sequences in self-attention.
- all tokens receive identical attention weights.
- values themselves determine attention weights directly.
- attention is symmetric.

The attention matrix must clearly correspond to:

query position × key position.

---

# 6. Visual objective

Primary visual:

A left-to-right computational graph.

Visual flow:

Input tokens
→ Q/K/V projections
→ QK^T
→ scaling + softmax
→ weighted sum over V
→ contextualized token representations

The attention matrix should be visually central.

---

# 7. Diagram specification

Input:

X represented as vertically stacked token vectors.

Q/K/V:

Three parallel projections from X.

Attention scores:

Matrix generated by QK^T.

Normalization:

Softmax along the key dimension.

Aggregation:

Attention matrix multiplied by V.

Do not use generic arrows.

Every arrow represents tensor flow.

---

# 8. Text content

Title:
Self-Attention: Content-Dependent Information Aggregation

Supporting statement:
Each query constructs its representation by selectively aggregating
information from the values of other tokens.

---

# 9. Acceptance criteria

- [ ] Q, K and V originate from the same X.
- [ ] Attention weights are visibly query-dependent.
- [ ] Softmax dimension is not visually ambiguous.
- [ ] The weighted aggregation uses V.
- [ ] The core computation is understandable without speaker narration.
